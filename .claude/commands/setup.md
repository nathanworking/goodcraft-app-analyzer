# /setup - Interactive Product Analysis Setup

Start a guided, step-by-step session to fill out your Founder Context and Product Spec.

## What This Does

Walks you through two documents interactively:

1. **Founder Context** (6 sections)
   - Technical Background
   - Domain Experience
   - Existing Distribution
   - Time & Resources
   - Goals & Risk Tolerance
   - Constraints

2. **Product Spec** (14 sections)
   - The Thesis (Problem, Insight, Product)
   - Who This Is For
   - Category & Positioning
   - Core Principles
   - MVP Features
   - Exclusions
   - Tech Stack
   - Pricing
   - Landing Page
   - Legal & Compliance
   - Distribution Strategy
   - Execution Plan
   - Founder Rules
   - Success Metrics

## Instructions

Read the skill at `.claude/skills/interactive-setup.md` and follow its workflow.

Start by asking the user what they'd like to do:
- Start fresh with both documents
- Only Founder Context
- Only Product Spec
- Resume/edit existing files

Then guide them through each section conversationally, one at a time.

After completion, save files to:
- `founder-context.md`
- `product-spec.md`

Offer to run the analysis or let them review first.
