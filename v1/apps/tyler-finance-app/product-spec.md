Investment Governance App – Founder Roadmap Workbook
This workbook is the single source of truth for designing, building, and launching your investment governance software company. It is not a pitch deck. It is not marketing copy. It is an execution guide.
You do not add features unless they clearly support the core thesis: reducing behavioral risk in long-term wealth building.

SECTION 1. THE THESIS (LOCKED)
The Problem
People with real money do not fail because of ignorance. They fail because of behavior.
Too many accounts. Too much data. Too much access. Too many impulses.
The Insight
Tracking money does not protect wealth.
Rules protect wealth.
The Product Definition
A personal investment governance system that:
Forces users to define rules first
Enforces those rules automatically
Surfaces action only when rules are violated
Otherwise stays silent
Silence is success.

SECTION 2. WHO THIS IS FOR (AND WHO IT IS NOT)
Ideal User
Age 35–55
Household net worth $500K–$5M
Multiple investment accounts
Spouse involved in finances
Some crypto exposure
Fear of self-sabotage more than fear of underperformance
Explicitly Not For
Beginners
Day traders
Yield chasers
Anyone who wants daily visibility
If someone wants excitement, they are not the customer.

Category Name

SECTION 4. CORE PRODUCT PRINCIPLES
Rules before data
Engagement reduction over engagement growth
Manual input before automation
Bands over targets
Scheduled visibility only
No recommendations, ever
If a feature violates any of these, it does not ship.

SECTION 5. MVP FEATURE SET (NON-NEGOTIABLE)
5.1 Onboarding: The Moat
Required before anything else unlocks.
User defines:
Time horizon
Target allocation by asset class
Drift bands per asset class
Rebalancing cadence
Crypto policy
Spouse inclusion
Never-do rules
No skipping. No defaults.

5.2 Manual Portfolio Input
Accounts:
Account name
Owner (self or spouse)
Asset class
Dollar value
Crypto:
Asset
Location (cold storage, exchange)
Snapshot price
Manual input is a feature, not a bug.

5.3 Master Allocation Engine
Calculates:
Household total
Asset class subtotals
Actual percentages
Drift vs target
Band violations
Default view is numeric. Charts are secondary.

5.4 Governance Logic
Rules enforced by the system:
No alerts unless bands are breached
No performance metrics outside review windows
Cooling-off periods before any action
Immutable history of decisions
If no rules are violated, the system explicitly tells the user to close the app.

5.5 Review Mode
Unlocked only on scheduled dates.
Allows:
Full allocation visibility
Drift alerts
Approved actions
Notes to future self
Outside review mode, everything is read-only.

SECTION 10. LEGAL & COMPLIANCE GUARDRAILS

Never suggests allocations
Never recommends assets
Never optimizes returns
