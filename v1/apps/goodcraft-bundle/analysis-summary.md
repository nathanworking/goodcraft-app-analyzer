## Executive Summary

Three solid products become significantly stronger as a unified venture. The bundle creates distribution leverage, increases LTV, and builds a competitive moat that point solutions cannot match.

**Primary Opportunity:** The Webflow professional tooling market is fragmented. No competitor offers a unified platform covering images, scripts, and CMS operations. The Workshop fills this gap with a compelling price point.

**Primary Risk:** Managing three products as a solo founder is a focus challenge. Distribution remains the constraint—excellent products still need users to find them.

## Why Bundle > Individual Products

### 1. Distribution Multiplier

Each product becomes a customer acquisition channel:
- Transform user (images) → discovers Script (code) → discovers Manage (CMS)
- Manage user (AI detection) → needs Transform (images for CDN)
- Script user (Git sync) → needs Manage (CMS operations)

**Result:** 3x the touchpoints, shared marketing costs.

### 2. LTV Amplification

| Metric | Individual | Bundle |
|--------|------------|--------|
| ARPU | ~$10/mo | $15/mo |
| Expected Retention | 18 months | 24+ months |
| Estimated LTV | $180 | $360+ |
| Improvement | — | **2x** |

Bundle users are more integrated into workflows = higher switching costs = longer retention.

### 3. Competitive Moat

**Individual products:** Each can be copied by a focused competitor.

**Bundle:** To match GoodCraft, a competitor must:
- Build an image optimization pipeline
- Build a Git-synced script manager
- Build an AI-powered CMS tool
- Integrate all three seamlessly

This is 3x the effort. The bundle creates compound defensibility.

### 4. Pricing Power

| Scenario | Monthly Revenue |
|----------|-----------------|
| 100 users × Transform ($8) | $800 |
| 100 users × Script ($6) | $600 |
| 100 users × Manage ($12) | $1,200 |
| **100 users × Bundle ($15)** | **$1,500** |

Same 100 users, but bundle captures more value while delivering more value.

No existing product offers:
- Image optimization + Code management + CMS automation

The closest alternatives require using 3+ separate tools:
- Images: Cloudinary / ImageKit / manual
- Scripts: Finsweet / DIY / embed fields

**GoodCraft is the only integrated solution.**

## Risk Assessment

### Focus Risk: HIGH
Managing three products requires discipline. Mitigate by:
- Prioritizing Transform (lead product)
- Setting clear "ignore for now" lists per product
- Time-boxing maintenance vs. new features

### Technical Risk: LOW
All products use proven technology. Shared stack reduces complexity.

### Market Risk: LOW-MEDIUM
Webflow market is established. Risk is Webflow building native features. Mitigation: stay ahead on professional features they won't build.

### Financial Risk: LOW
Infrastructure costs scale with revenue. Bootstrap-friendly unit economics.

## Recommended Spec Modifications

### 1. Raise Bundle Price to $19/month
- Current $15 may leave value on table
- Still 27% savings vs. individual ($26)
- Test both prices

### 2. Prioritize Unified Dashboard
- Single entry point for all products
- Reduces cognitive load
- Increases perceived value of bundle

### 3. Create "Quick Wins" Cross-Sell Moments
- After optimizing 10 images → suggest Script
- After creating collection → suggest Transform
- After deploying script → suggest Manage

### 4. Formalize Bundle Billing
- Single Stripe subscription for bundle
- Easy upgrade from individual products
- Clear feature comparison matrix
